## 🚀 Quick Start

### Requisitos
- Cuenta en [n8n.io](https://n8n.io)
- API Key de [Groq](https://console.groq.com)
- Python 3.9+ (para scripts opcionales)
- Git

### Setup inicial

```bash
git clone https://github.com/Carolina053Peke/AI-Automation-Avanzado.git
cd AI-Automation-Avanzado

# Descarga los workflows de n8n
# Importa cada semana desde JSON

# Configura variables de entorno
cp .env.example .env
# Agrega tus API keys
```
